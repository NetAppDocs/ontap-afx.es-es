= Flujo de instalación y configuración para los sistemas de almacenamiento AFX 2K
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para instalar y configurar tu sistema de almacenamiento AFX 2K, revisa los requisitos de hardware, prepara tu sitio, instala los switches, instala y cablea los componentes de hardware, enciende el sistema y configura tu clúster ONTAP AFX.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"]link:../install-setup/install-setup-requirements.html["Revise los requisitos de instalación del hardware"]
[role="quick-margin-para"]
Consulta los requisitos de hardware para instalar tu sistema de almacenamiento AFX 2K.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"]link:../install-setup/prepare-hardware.html["Prepárate para instalar tu sistema de almacenamiento AFX 2K"]
[role="quick-margin-para"]
Prepárate para instalar tu sistema de almacenamiento AFX 2K preparando el sitio, comprobando los requisitos ambientales y eléctricos, asegurando suficiente espacio en rack, desempaquetando el equipo, verificando el contenido con el albarán de entrega y registrando el hardware para soporte.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"]link:install-switches.html["Instala los switches de tu sistema de almacenamiento AFX 2K"]
[role="quick-margin-para"]
Instala los switches Cisco Nexus 9808, 9332D-GX2B o 9364D-GX2A en el armario o en el rack. Instala un kit de panel de paso si usas el switch Cisco Nexus 9364D-GX2A.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Cuatro"]link:deploy-hardware.html["Instala el hardware de tu sistema de almacenamiento AFX 2K"]
[role="quick-margin-para"]
Instale los kits de rieles para su sistema de almacenamiento y estantes.  Asegure su sistema de almacenamiento en el gabinete o rack de telecomunicaciones.  A continuación, deslice los estantes sobre los rieles instalados.  Por último, coloque dispositivos de gestión de cables en la parte trasera del sistema de almacenamiento para organizar los cables.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinco"]link:cable-hardware.html["Conecta los controladores y las estanterías de tu sistema de almacenamiento AFX 2K"]
[role="quick-margin-para"]
Para cablear el hardware, primero conecte los nodos del controlador de almacenamiento a su red, luego conecte los nodos del controlador y los estantes de almacenamiento a los conmutadores del clúster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Seis"]link:power-on-configure-switch.html["Enciende y configura los switches de tu sistema de almacenamiento AFX 2K"]
[role="quick-margin-para"]
Enciende y configura los switches de tu sistema de almacenamiento AFX 2K. Consulta las instrucciones de configuración para los switches Cisco Nexus 9808, 9332D-GX2B y 9364D-GX2A.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png["Siete"]link:power-on-hardware.html["Enciende tu sistema de almacenamiento AFX 2K"]
[role="quick-margin-para"]
Encienda cada estante de almacenamiento y asígnele una identificación de estante única antes de encender los nodos del controlador para identificar claramente cada estante en la configuración.
